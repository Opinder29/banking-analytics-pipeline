# 🏦 Banking Analytics Pipeline

A end-to-end data engineering project simulating a real banking analytics system.

## 🎯 Project Overview
This project demonstrates core data engineering skills including:
- SQL database design with 15 banking tables
- Complex SQL queries and analysis
- Star schema data modeling
- ETL data mapping
- Apache Spark data processing

## 🛠️ Tech Stack
- MySQL — relational database
- Apache Spark — big data processing
- Python — scripting
- GitHub — version control
